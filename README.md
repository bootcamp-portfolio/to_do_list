# To-Do List App

Flutter 기반 할 일 관리 앱 학습 프로젝트입니다.

## 프로젝트 개요
Flutter 프로젝트 구조와 모바일 앱 개발 흐름을 익히기 위한 실습 저장소입니다. 세부 기능은 실제 앱 코드를 기준으로 확인해 주세요.

## 기술 스택
- Flutter
- Dart

## 실행 방법
1. Flutter SDK를 설치합니다.
2. 저장소를 클론합니다.
3. 프로젝트 루트에서 의존성을 설치합니다.
   ```bash
   flutter pub get
   ```
4. 에뮬레이터 또는 연결된 기기에서 실행합니다.
   ```bash
   flutter run
   ```
